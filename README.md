# Budget tracker - Personal Finance Tracker

## Project Description
Budget Tracker is a responsive web application designed to help users track their daily expenses, manage budgets, and monitor their financial transactions effortlessly with an intuitive and interactive user interface.

## Technologies Used
- HTML5: For structured web page elements and semantic markup.
- CSS3: For styling, responsive layouts, and modern UI design.
- JavaScript (ES6): For adding interactivity, handling user inputs, and dynamic DOM manipulation.
- Git & GitHub: For version control and source code management.
- Netlify: For cloud hosting and continuous deployment.

## Deployment Process Summary
1. Organized and structured all project files (index.html, style.css, and script.js) locally in VS Code.
2. Initialized Git, committed the project changes, and pushed the code to a public GitHub repository.
3. Connected the GitHub repository to Netlify for automated cloud builds.
4. Configured a custom site name on Netlify and verified that the live deployment build succeeded without errors.

## Challenges Encountered During Deployment
Initially, ensuring that all relative paths for CSS and JavaScript assets linked correctly in the production build required minor directory path adjustments. Setting up continuous deployment also required verifying that the correct publishing branch (main) was selected on Netlify.

## Lessons Learned
This deployment module provided hands-on experience in moving a static web application from a local development environment to a live production server. I gained a deep understanding of continuous deployment workflows, cloud hosting pipelines, and how pushing updates to GitHub automatically triggers instant web updates via Netlify.
